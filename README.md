# Best Cars Dealership

## Project Description
A full-stack web application for managing car dealership reviews across the United States.
Built with Django, React, Node.js, MongoDB, and deployed on IBM Cloud using Kubernetes.

## Technologies Used
- Frontend: React.js, HTML, CSS, Bootstrap
- Backend: Python, Django, Node.js, Express
- Database: SQLite, MongoDB
- Cloud: IBM Code Engine, Kubernetes, Docker
- DevOps: GitHub Actions (CI/CD)

## Features
- View car dealerships by state
- User registration and authentication
- Post and view dealer reviews
